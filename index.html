What this rebuilds

  • Heartbeat proves the socket is still alive. It never fans out to contacts.
  • Session TTL catches a dead phone that never sends a close frame.
  • Debounce stops online/offline flapping on a 300ms reconnect.
  • Push only fires on state change, and only to online subscribers.
  • Multi-device: you stay online until the last session dies.

Demo timings are compressed (2s heartbeat, 6s TTL) so judges can see failure modes live. Production WhatsApp uses longer intervals plus connection-level TCP signals.
